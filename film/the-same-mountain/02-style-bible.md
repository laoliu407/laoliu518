# 02 视觉规范

> **第 2 版：纪录片质感。** 第 1 版追求"电影感"，画出来像 AI 短剧。这一版的标准是：**每一帧都要像真实的观察式纪录片截图。** 参考《舌尖上的中国》第一季里的乡村段落，或者 BBC 的人文纪录片。

---

## 一、三条铁律

1. **镜像铁律。** 同号镜头的 W 版和 A 版，机位、焦段、构图、主体位置、运动方向、动作节奏必须完全一致。观众要能"叠"在一起看。
2. **真实铁律。** 看起来像纪录片，而不是拍出来的戏。宁可普通，不要好看；宁可粗糙，不要精致。
3. **克制铁律。** 不讲道理。全片只有两句台词和结尾四行字幕。

## 二、为什么之前像 AI 短剧（对照表）

| AI 短剧的样子 | 纪录片的样子 |
|---|---|
| 电影感打光：轮廓光、光束、逆光剪影 | 只有现场本来的光：阴天、窗户、灯泡、炉火 |
| 浅景深，背景虚成光斑 | 景深较深，背景看得清 |
| 调色浓重：青橙色调、高反差、HDR | 机器直出的自然颜色，偏灰、低反差 |
| 人物皮肤光滑，或者皱纹刻意夸张 | 普通的皮肤：晒斑、高原红、干裂的嘴唇 |
| 表情戏剧化，像在演 | 面无表情，忙自己的事，不看镜头 |
| 服装像戏服，又新又干净 | 旧、褪色、打补丁、混搭 |
| 村子像布景，整洁好看 | 真实杂物：塑料盆、编织袋、胶鞋、电线、太阳能热水器 |
| 构图完美对称，仰拍显得英雄 | 平视，构图略有不完美 |
| 慢动作、平滑的推拉摇移 | 实时速度，固定机位或轻微手持 |
| 局部留色（只有一种颜色是彩色） | 颜色自然，辣椒的红靠衣服和道具朴素来衬托 |
| 2.39:1 宽银幕黑边 | 16:9 全画幅 |

## 三、分幕的光线

| 段落 | 光线 | 说明 |
|---|---|---|
| 序 + 第一幕 | 清晨浓雾，灰蓝色平光，没有阳光，略微欠曝 | 雾也是"藏住破绽"的工具 |
| 第二幕 | 室外是阴天平光；室内靠窗光和炉火 | 室内角落允许黑下去 |
| 四百年前 | 夜，雨，只有油灯和闪电 | 历史情景再现，但要像纪录片的再现，不像大片 |
| 第三幕 | 傍晚室内：小窗、炉火、头顶一盏灯泡 | 两边都有灯泡，真实，也是一组镜像 |
| 尾声 | 黑底白字 | — |

## 四、镜头语言

- **机器：** 按"Sony FX6 纪录片摄影机 + 35mm 或 50mm 定焦"来想象。光圈 f/5.6 到 f/8，景深较深。
- **机位：** 平视，或者摄影师自然站立、蹲下的高度。少用仰拍和航拍，S30 是全片唯一的航拍。
- **运动：** 第一幕和第三幕以固定机位为主（观察）；第二幕允许轻微手持（靠近劳动）。不用平滑的推拉摇移。
- **速度：** 实时，不用慢动作。
- **剪辑：** 剪在"不完美的瞬间"：人物刚好动了一下、烟刚好飘过。太完美的那一帧反而假。
- **动作接动作：** S07（锄头挥下接落地）和 S27（筷子按下接手指提起）。动作从一个半球开始，在另一个半球完成，剪辑点精确到帧。

## 五、人物

两位老人互为镜像：年龄、体型、姿态尽量一致。**第一幕只拍手、背影和剪影，第二幕 S18 才第一次露脸。**

- **W-ELDER 威信老人：** 68 岁左右的农妇。皮肤晒伤不均，有晒斑和高原红，花白头发裹在长条黑头帕里。褪色的藏青棉外套下面穿着便宜的花毛衣，围腰有污渍，旧解放鞋上全是灰。手大而粗，指甲缝里有泥。
- **A-ELDER 安第斯老人：** 68 岁左右的克丘亚族农妇，住在库斯科附近的高原。同样晒伤的皮肤和高原红，两条花白长辫，一顶落了灰的深棕色毡帽。旧的深棕色手织披肩（lliclla）下面穿着便宜的腈纶开衫，深色多层羊毛裙，脚穿轮胎凉鞋（ojotas）。手同样大而粗。

参考图提示词见 `gpt-images.md` 的 PART 0。参考图按"站在自家门口的纪录片人物肖像"来拍，不用摄影棚灰背景的设定图，那种图本身就带着 AI 感。

> **尊重原则。** 拍的是两位真实的农妇在干活，不是"民族风情"。不摆拍，不让她们对镜头笑。两位老人在画面里的地位完全对等。安第斯传统服饰常有鲜艳的颜色，这里选深色，是因为这是她干农活的日常衣服，不是在改变她的文化。

## 六、场景

- **W-VILLAGE：** 威信山区今天真实的样子：夯土房和砖房混在一起，灰瓦，有的墙是裸露的水泥；屋顶上有太阳能热水器，木电线杆上拉着电线；屋檐下挂着玉米；陡坡上是洋芋梯田；石灰岩山峰在低云里。
- **A-VILLAGE：** 库斯科附近克丘亚社区今天真实的样子：土坯房和石头房，瓦顶和铁皮顶混在一起；也有木电线杆和电线；古老的石砌梯田上种着洋芋；高山草甸，雪峰半隐在云里，几只羊驼。

**第一幕必须藏住的"破绽"：** 在 S12 揭示之前，A 版画面里不能出现雪峰、羊驼、毡帽、彩色洋芋和人脸。现代杂物（塑料盆、电线）两边都有，不算破绽。

## 八、字体与界面

全部字体可免费商用（SIL OFL 协议）。纪录片的字幕要朴素，不做特效。

| 用途 | 字体 | 规格 |
|---|---|---|
| 章节字幕（一座山 / 两座山 / 同一座山） | 思源宋体 Light | 字高约为画面高度的 3.5%，字距加宽，居中偏下；下方英文用 Cormorant Garamond，小一号 |
| 对白字幕、尾声字幕 | 思源宋体 Regular | 白色，底部居中 |
| 坐标、距离 | IBM Plex Mono Light | 60% 白，逐字打出，每字约 30 毫秒；放在各自画框的左下角 |
| 片尾品牌 | 思源宋体 Medium | 白色居中 |

界面元素只有三种：坐标（S13 出现，S19 结束时淡出）、古地图航线（S23）、分屏中缝（见下一节）。

## 九、分屏规范

- **左边永远是威信，右边永远是安第斯。** 这是以太平洋为中心的世界地图方向，和 S23 的古地图一致。
- 画面左右各占一半。素材按 16:9 生成，主体放在中间，剪辑时裁取中间的一半放进分屏。
- 中缝是一条 2 像素的暖白细线，不透明度 35%。
- S13 中缝"打开"；S29 中缝"消失"，两张桌子合成一张。

## 十、画幅与后期

- **画幅：16:9 全画幅，不加黑边。** 输出 3840×2160 或 1920×1080，25 帧。
- **放大：** Grok 生成的视频分辨率不够时，用剪映或 Topaz 放大。放大时关掉"锐化"和"人脸增强"，这两项会让画面变回 AI 感。
- **调色：** 目标是"机器直出"。降低反差和饱和度，不做风格化调色。找一张真实的纪录片截图当参考，所有镜头往它靠。
- **质感：** 整体加一层轻微的数字噪点（不是浓重的胶片颗粒）；画面太锐利的镜头稍微柔化一点。
- **太稳的镜头：** Grok 生成的画面如果稳得不自然，可以在剪辑软件里加一点极轻微的手持晃动（第二幕）。

## 十一、一致性方法

1. **参考图贯穿全程。** 两张人物参考图和两张场景参考图，每次生图都附上。
2. **一幕一个会话。** 每幕开一个新的 ChatGPT 对话，重新上传任务单和参考图，防止风格漂移。
3. **镜像出图法。** 先生成 W 并选定，再让 ChatGPT 按 W 的构图出 A。不要两边各自从文字生成，否则构图对不上。
4. **同组同运动。** W 和 A 用完全相同的 Grok 提示词。
5. **短镜头。** 大多 2 到 4 秒。镜头越短，AI 出错的机会越少。
6. **手部风险。** 手和食物的接触最容易出错。多生成几条挑选，实在不行换 Sora。
7. **命名规则。** `S07A-2.mp4`：镜头号 + 第几条。

## 十二、选片检查表

每张图、每条视频，过一遍这几个问题，有一条是"是"就重做：

- [ ] 看起来像海报、广告或短剧剧照？
- [ ] 有明显的打光痕迹（轮廓光、光束、光斑）？
- [ ] 人物的皮肤太光滑，或者皱纹夸张得像特效化妆？
- [ ] 人物在"演"：表情丰富，或者看着镜头？
- [ ] 衣服和环境太干净、太整齐？
- [ ] 颜色太鲜艳，或者调色风格很重？
- [ ] 手指数量、手和物体的接触有问题？
