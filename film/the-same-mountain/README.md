# 《同一座山》THE SAME MOUNTAIN

雷大卷辣椒面品牌短片｜约 3 分 10 秒｜画幅 2.39:1｜中文字幕（另备英文字幕版）

> 一句话：把安第斯山和乌蒙山，剪成同一座山。

---

## 创意阐述

洋芋原产南美安第斯山。辣椒属植物也起源于安第斯一带，后来在美洲各地被驯化。几千年来，安第斯山的克丘亚人用一块平石头来回碾碎辣椒，蘸着洋芋吃。

四百多年前，这两种植物漂洋过海来到中国。1591 年的《遵生八笺》里，辣椒还被叫作"番椒"。

今天，在一万八千公里外的滇东北乌蒙山区，威信人围着烙锅，用洋芋蘸辣椒面。

两座山互不相识，同样高寒，同样贫瘠，却吃着同一顿饭。

全片用镜像剪辑讲这件事：每一个威信镜头，都有一个构图和动作完全一致的安第斯镜头。

- 前一分钟，观众以为只有一座山；
- 一只羊驼转过头，他们才发现是两座；
- 结尾两张饭桌合成一张，他们才明白，是同一座。

片子不讲道理，只在最后摆出几行事实。

## 导演阐述（报名时可用）

我们没有编故事。洋芋和辣椒的旅程是真实的，两座山上的饭桌也是真实的。我们只做了一件事：把地球两端的两个画面并排放在一起，让观众自己发现它们是一样的。

全片只有两句台词，语言不同，意思相同，字幕一字不差。"在最难活下去的地方，人类找到了同一种活法"，这句话片子里没有说，我们希望观众自己说出来。

## 制作流程（按顺序做）

1. **定参考图。** 用 ChatGPT 生成两位老人的人物设定图、两个村子的场景图（见 02 文件）。之后每次生图都附上这四张图。
2. **先做音乐。** 按 04 文件生成四段音乐，拼成一条 3 分 10 秒的音轨。画面跟着音乐剪，节奏才准。
3. **生成首帧。** 每组镜像先出威信版，挑最好的一张；再用"镜像模板"让 ChatGPT 按同一构图出安第斯版。
4. **生成视频。** 用 Grok Imagine 图生视频。同一组的两个镜头用完全相同的运动提示词。每个镜头出 3 到 4 条，挑最好的一条。生成的声音全部不用。
5. **剪辑。** 用 DaVinci Resolve（免费）或剪映专业版，按 01 文件的时间码剪。
6. **调色统一。** 所有镜头套同一个调色方案，最后整体加一层胶片颗粒。这一步是让 AI 素材看起来像同一部片子的关键。
7. **声音。** 铺音效、对白、旁白，混音输出。

预估生成量：48 个视频镜头，每个出 3 到 4 条，共约 150 到 200 次视频生成。

## 需要你准备的

- [ ] **高清产品实拍。** 仓库里那张产品图只有 260×390，片尾不够用。最好拍一段实拍视频：倒辣椒面、泼热油。
- [ ] **威信方言台词。** 请一位本地老人说"来嘛，吃。"，手机在安静的屋里录就行。
- [ ] **结尾旁白。** 请同一位老人念结尾四行字幕（见 04 文件）。
- [ ] **克丘亚语台词。** 请一位克丘亚语母语者录"Hamuy, mikhuy."（来，吃。），并确认用法，可以在线找译者或配音员。
- [ ] **实录音效（强烈推荐）。** 烙锅的滋啦声、锄头挖土、火塘噼啪、石臼舂辣椒。真实的声音最能提升质感。
