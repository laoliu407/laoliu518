## 二、分场剧本

### 序（0:00–0:19）

**S01｜0:00–0:05｜黑场**
高山上的风。0:02，一声闷响：锄头砸进泥土。0:04，又一声。

**S02W｜0:05–0:11**
极远景。云海里，一道石灰岩山脊慢慢浮现，镜头极缓地推进。0:06，一支竹笛吹出一个长音。

**S03A｜0:11–0:19**
雾漫过画面，遮住剪辑点。还是那道山脊，其实已经换成了安第斯山。观众不会察觉。
0:14，字幕淡入：**一座山**（ONE MOUNTAIN）。0:19 淡出。

### 第一幕 一座山（0:19–1:01）黎明，浓雾

> 导演说明：这一幕要让观众相信这是同一个地方。所有暴露"这是南美"的细节，包括雪峰、羊驼、毡帽、彩色洋芋和人脸，一律藏住。W 和 A 交替出现，每个镜头约 3 秒，节奏平稳。声音在切点处不断，连成一片。

| S05W | 0:25–0:27 | 屋内低机位，夯土房的木门被推开，蓝色晨光和雾涌进黑屋 |
| S05A | 0:27–0:29 | 同构图，土坯房的木门 |
| S06W | 0:29–0:32 | 背影，老人背着竹背篓走上雾中小路，渐渐消失 |
| S06A | 0:32–0:35 | 同构图，老人背着织布包袱，头裹披巾，剪影形状和 W 一致 |
| S07W | 0:35–0:37 | 仰拍特写，一双手把锄头高高举起，开始往下挥 |

### 揭示（1:01–1:11）

**S12A｜1:01–1:07**
还是 S11A 的构图。一阵风吹散了雾，远处露出巨大的雪峰。老人身旁，一只羊驼慢慢转过头，看向镜头。
笛声断在半句。寂静里只有风，和羊驼的一声轻哼。

**S13｜1:07–1:11｜画面裂开**
画面正中出现一道细竖线，像一扇门被推开。A 的画面滑到右半边，左半边滑进 W 的老人，两人姿势一模一样。
第二支笛子接上了第一支没吹完的那半句。
1:08，竖线下方淡入：**两座山**（TWO MOUNTAINS）。左右画框角落逐字打出坐标：
左：`27°50′N 105°03′E｜云南·威信`
右：`13°31′S 71°58′W｜秘鲁·库斯科`

### 第二幕 两座山（1:11–1:50）白天

> 导演说明：现在观众知道是两个地方了，开始主动找"下一组对应"。节奏越来越快，石头撞击的声音变成音乐的鼓点。

| 镜头 | 时间 | 画面 |
|---|---|---|
| S14 分屏 | 1:11–1:16 | 左：双手捧着刚挖的黄皮洋芋；右：双手捧着安第斯原生洋芋，深紫、黑、黄，形状奇特 |
| S15W | 1:16–1:19 | 火塘里，手把洋芋埋进炭灰 |
| S15A | 1:19–1:22 | 土块垒成的窑（huatia）烧得通红，手把洋芋埋进去 |
| S16W | 1:22–1:24 | 铁锅里焙炒干辣椒 |
| S16A | 1:24–1:26 | 陶土浅盘（callana）上烘烤干辣椒 |
| S17 蒙太奇 | 1:26–1:40 | 石臼舂辣椒和安第斯石磨（batán）碾辣椒交替，剪辑越来越快（见下表） |
| S18W | 1:40–1:43 | **第一次露脸**：老人眼睛特写，在烟里眯着眼 |
| S18A | 1:43–1:46 | 同构图，同样的皱纹，同样眯着眼 |
| S19 分屏 | 1:46–1:50 | 左右同时：烤好的洋芋被掰开，热气爆出（慢动作）。音乐冲到最高—— |

**S17 剪辑节奏（共 14 秒）**

| 顺序 | 素材 | 时长 |
|---|---|---|
| 1 | S17a W 木杵砸进石臼 | 1.5 秒 |
| 2 | S17b A 石磨来回碾 | 1.5 秒 |
| 3 | S17a / S17b | 各 1 秒 |
| 4 | S17c W 辣椒碎微距 / S17d A 辣椒酱微距 | 各 1 秒 |
| 5 | a / b / a / b | 各 0.75 秒 |
| 6 | a / b / a / b | 各 0.5 秒 |
| 7 | S17e 光柱里飘浮的辣椒粉尘（音乐换气） | 2 秒 |

每一刀都切在鼓点上。

**1:50｜硬切黑，静音 1 秒。**

### 四百年前（1:51–2:13）夜，暴风雨

**S20｜1:51–1:54**
黑场。深海的低频轰鸣。字幕：**四百年前**（400 YEARS AGO）。

**S21｜1:54–1:59**
极远景。暴风雨中的太平洋，一艘 16 世纪的西班牙大帆船爬上巨浪。一道闪电照亮了整片海。雷声。

**S22｜1:59–2:03**
船舱里，油灯摇晃。一只麻袋被撑裂，洋芋滚落在湿木板上；一只干辣椒掉在洋芋中间（贴地特写，慢动作）。

**S23｜2:03–2:09｜界面：古地图**
羊皮纸上的太平洋古地图（中国在左，美洲在右）。一条墨线从安第斯山出发，向左划过整个太平洋，抵达中国西南。两端依次打出坐标，墨线中段浮出 `18,000 KM`。镜头缓缓推近地图。

**S24｜2:09–2:13｜闪电变成火**
闪电劈下，画面全白（S24a）。在最白的那一帧，切到烙锅下的炭火"轰"地燃起（S24b）。
雷声的尾巴直接变成热油的滋啦声。

### 第三幕 同一座山（2:13–2:52）傍晚，火光

| 镜头 | 时间 | 画面 |
|---|---|---|
| S25W | 2:13–2:17 | 顶拍，烙锅烧热，油面颤动，筷子把洋芋片铺上去，滋啦作响 |
| S25A | 2:17–2:21 | 同构图，陶土浅盘上，手指翻烤洋芋块 |
| S26W | 2:21–2:24 | 干碟特写：一小碟颗粒分明的辣椒面，火光侧照 |
| S26A | 2:24–2:27 | 同构图，石碗里的安第斯辣椒酱（uchucuta） |
| S27W | 2:27–2:29 | 筷子把洋芋按进辣椒面 |
| S27A | 2:29–2:31 | 手指把洋芋从辣椒酱里提起。**动作接动作**：W 往下按，A 往上提 |

**S28｜2:31–2:38｜分屏**
左右分屏。两位老人分别坐在长桌的两端，都朝着画面中缝。
2:32，左边的威信老人把碟子往中间推："来嘛，吃。"
2:34，右边的安第斯老人把石碗往中间推："Hamuy, mikhuy."
两句台词下方，是**一字不差的同一行字幕**：**来，吃。**

**S29｜2:38–2:44｜合成一张桌子**
中缝慢慢消失。两张桌子连成一张长桌，两位老人仿佛隔着桌子对坐。左边窗外是乌蒙山，右边窗外是安第斯山。镜头缓缓推近。双笛齐奏主旋律。

**S30｜2:44–2:52｜同一座山**
两口锅升起的热气填满画面，转场成黄昏的航拍：左边乌蒙山的梯田和瓦房，右边安第斯山的石梯田和雪峰，连成一条不间断的山脊。镜头缓缓升高。
2:44，字幕：**同一座山**（THE SAME MOUNTAIN）。音乐到达最高点。
