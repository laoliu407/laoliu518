# Grok 视频任务单｜《同一座山》

> **第 2 版：纪录片质感。** 去掉了慢动作和平滑的推拉摇移，因为这些是广告和短剧的标志。现在是固定机位或轻微手持，实时速度，像真的在现场拍的。

## 给你看的用法

全部 48 条视频。每一条都是：**上传对应的首帧图片 + 粘贴下面的提示词**。首帧图片来自 `gpt-images.md`。

- 标着两个文件名的条目（比如 `S04W.png` 和 `S04A.png`），两张图**分别各生成一次，用完全相同的提示词**。这是镜像效果的关键。
- 每条生成 3 到 4 次，挑动作最自然、没有变形的一条。**动作越普通越好**，人物动作夸张、表情戏剧化的版本直接淘汰。
- 时长用 Grok 的默认长度（约 6 秒）就行。每条后面的"剪后"是剪辑时实际用的长度。
- 视频按图片同名保存，比如 `S04W.mp4`；同一条的多个版本加后缀，比如 `S04W-2.mp4`。
- Grok 生成的声音全部不用，后期会重新配。
- S21、S22 场面复杂，效果不好的话改用 ChatGPT 里的 Sora，提示词通用。
- S23（古地图）不需要生成视频，剪辑时直接用图片做动画。

## INSTRUCTIONS FOR GROK

This is the shot list for an observational documentary called THE SAME MOUNTAIN. The user uploads a first-frame image whose file name starts with a shot ID (for example S04W). Find that ID below and animate the image using exactly that prompt. Keep the image's composition, people and light unchanged.

Every clip must look like real documentary footage: real-time speed (no slow motion), a static tripod or a subtly handheld camera, natural unhurried movement, people unaware of the camera, no dramatic expressions, no cinematic camera moves. Do not add music, captions, text or logos.
